# Initio Display Manager

Initio — это минималистичный оконный менеджер для X11, полностью написанный на Python. Проект предоставляет базовый экран входа в систему (GUI) и простую среду рабочего стола с панелью задач и управлением окнами.

## 🚀 Имеет

- (21-04-26) Экран входа (DM): аутентификация через PAM (Pluggable Authentication Modules).
- (21-04-26) Оконный менеджер (WM).
- (21-04-26) Интеграция с rofi для запуска приложений.
- (21-04-26) Автоматическая настройка: скрипты для установки системных зависимостей и регистрации сессии в X11.
- (22-04-26) Кривой тайлинг (включается через настройки; для применения нужен перезаход в сессию).

## 📦 Требования

- ОС: Linux (поддерживаются системы с pacman или apt).
- Python 3.11+.
- X11 Server.

## 🛠 Установка

### 1. Клонирование

```bash
git clone https://github.com/QLegacy/initio.git
cd initio
```

### 2. Подготовка окружения

При первом запуске `main.py` автоматически вызывает установщик зависимостей (`install/libs.py`), который:

- установит системные пакеты (`python-pam`, `python-xlib`, `rofi`, `tk` и др.);
- доустановит недостающие Python-библиотеки через pip;
- создаст `.desktop` файл в `/usr/share/xsessions/` для выбора Initio в меню вашего экрана входа.

### 3. Сборка (опционально)

Если вы хотите скомпилировать проект в бинарный файл:

```bash
python3 build.py
```

Скрипт использует PyInstaller и выведет инструкции по установке скомпилированного файла в `/opt` и регистрации сессии.

## 🖥 Использование

После установки вы можете выйти из текущей графической сессии и выбрать «Initio» в меню выбора сессии вашего дисплейного менеджера (например, SDDM, GDM, LightDM).

- **Вход:** введите имя пользователя и пароль.
- **Запуск приложений:** нажмите синюю кнопку на панели — откроется rofi.
- **Управление окнами:**
  - перетаскивание: ЛКМ по заголовку окна;
  - изменение размера: ЛКМ по краям окна.

## ⚠️ Важное предупреждение

- **Права доступа:** не выставляйте SUID-бит (`chmod +s`) на Initio. Он запускается от имени пользователя, а PAM-проверка пароля этого же пользователя работает и без повышенных привилегий. Проверка пароля *другого* пользователя без root может не пройти.
- **Зависимости:** `install/libs.py` сначала ставит пакеты через менеджер пакетов системы и использует pip (с флагом `--break-system-packages`) только если модуль всё ещё не импортируется.
